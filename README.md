# Nature vs Social Media

Interactive courtroom website for the English oral presentation "The Case of Nature vs Social Media".

## Put it online with GitHub Pages
1. Create a new public repository on GitHub (for example `nature-vs-social-media`).
2. Upload everything in this folder (`index.html`, `README.md` and the whole `assets` folder), keeping the folder structure.
3. In the repository: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/nature-vs-social-media/`.

## During the presentation
- Click an evidence marker on the map to open a crime scene. `←` `→` scroll through the photos and videos, `Page ↓` / `Page ↑` jump to the next / previous scene, `Esc` goes back to the map.
- Click the gavel on the first screen to strike it again (with sound).
- "+ Add photo / video" in a crime scene adds extra media on that computer only (saved in the browser). To add media for good, put the file in `assets/media/` and add it to the `media` list of that place in `index.html`.
- Footer: "Reset the map" marks every scene as unexamined again before the real presentation.
